# Men Salon — Luxury Barbershop & Hair Salon HTML5 Template

A modern, responsive, dark-luxury multi-page and one-page HTML5/CSS3/Vanilla JS template crafted for contemporary men's salons, barbershops, and grooming studios (`#171311` espresso charcoal, `#C8A46A` brushed gold, `Playfair Display` & `DM Sans`).

## Included Pages & Hero Layouts
- `index.html` — Main Multipage Homepage (Collage Hero + Vertical Rotating Title Slider)
- `home-onepage.html` — One-Page Smooth Scroll Edition
- `home-slider.html` — Fullscreen Hero Banner Slider Edition
- `home-video.html` — Fullscreen Video Background Hero Edition
- `home-image.html` — Static Hero Image + 5.0 Trust Pill Edition
- `about-us.html` — Studio Story, Rotating SVG Badge, 1998/2015/2026 History Timeline & Team
- `services.html` — Filterable Service Menu (`01`–`06`) with Hover Reveal & Direct Booking
- `reviews.html` — Client Testimonials + Interactive Review Submission (`localStorage`)
- `our-team.html` — Master Barbers with Dual-Image Hover Swap & Barber-Specific Booking
- `gallery.html` — Filterable 3-Column Masonry Lookbook & Fullscreen Lightbox (`×`, `❮`, `❯`, keyboard)
- `booking.html` — Appointment Reservation Engine, Time Slot Picker, Sunday Closed Check & Saved Bookings
- `blog.html` & `blog-single.html` — Grooming Journal with Live Search, Category Tabs, Pagination & Comments

## Running Locally
Start any static server inside `men-salon/` (for example on port `5500`):
```powershell
python -m http.server 5500
```
Then open `http://localhost:5500/index.html`.
